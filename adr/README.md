# Architecture Decision Records

Each file records one significant decision: the context, the choice and its consequences.

## Conventions

- File name: `NNNN-short-title.md`, numbered from `0001` and never reused.
- Use [`0000-template.md`](0000-template.md) as the starting point.
- Status is one of `proposed`, `accepted`, `deprecated` or `superseded by NNNN`.
- Do not rewrite an accepted ADR. Write a new one that supersedes it.
- Findings from [`../OTHERS.md`](../OTHERS.md) that shape a decision should be linked from the ADR.
